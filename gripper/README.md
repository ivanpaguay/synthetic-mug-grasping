# Gripper model

The Robotiq 3F gripper geometry is **not redistributed** here.

It comes from the ROS-Industrial `robotiq` package (BSD licence),
URDF `robotiq-3f-gripper_articulated` with its visual and collision meshes.
Get it from the ROS-Industrial repository and convert it to USD with the Isaac Sim
URDF importer; `isaac/` expects the articulated, fixed-base USD.
